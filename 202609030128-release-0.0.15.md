# Release 0.0.15 / 发布 0.0.15

- Narrow browser lifecycle host values to typed String, Bool, and JsNullish boundaries under Calcit 0.13.75.
- Keep the internal scheduling API on Option instead of leaking JavaScript nullish values.
- Replace the JSON quality checker with the native Cirru EDN v2 baseline and enforce zero dynamic method dispatch.
- 将浏览器生命周期宿主值收窄到 String、Bool 与 JsNullish 边界，内部调度 API 继续使用 Option。
- 用原生 Cirru EDN v2 质量基线替换 JSON 检查器，并对动态方法分派执行零容忍门禁。
